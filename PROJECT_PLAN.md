# Project Plan

## Phase 1 — Foundation
Generate synthetic complaints, investigations, CAPAs, changes, and training records.

## Phase 2 — Analysis
Calculate:
- quality-event aging and overdue rate
- high-risk open events
- CAPA aging and effectiveness
- change implementation cycle time
- root-cause recurrence
- training / cross-training coverage
- single-point-of-failure exposure

## Phase 3 — Dashboard
Build management-review views with KPI cards, trends, risk tables, and change-management performance.

## Phase 4 — Portfolio polish
Add screenshots, methodology, QC checks, data dictionary, and resume-ready quantified bullets.
