# Synthetic Data

All CSV files in this folder contain fictional data generated specifically for this portfolio project.

The files are used to demonstrate QMS analytics, KPI calculation, risk prioritization, CAPA and change management analysis, training coverage, and management review decision support.

No employer, client, patient, sponsor, confidential, proprietary, or personally identifiable data are included.

The synthetic records are designed to be realistic enough for analytical testing while remaining entirely fictional.
